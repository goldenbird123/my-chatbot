\# 我的聊天机器人 AI Agent



一个基于 Python + Ollama + LangChain 的个人 AI Agent 项目。





\## 项目介绍



本项目实现一个本地运行的智能助手。



功能：



\- 大语言模型对话

\- Ollama本地模型调用

\- Memory记忆系统

\- 向量数据库存储

\- Agent架构





\## 技术栈



\- Python 3.11

\- LangChain

\- Ollama

\- ChromaDB

\- Qwen





\## 项目结构





```

my-chatbot

│

├── 应用

├── 核心

├── 记忆

├── 测试

├── config.py

└── requirements.txt

```





\## 运行





安装依赖：



```bash

pip install -r requirements.txt

```





启动：



```bash

python main.py

```
